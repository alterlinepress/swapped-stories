# Swapped Stories

Welcome to the project files for the Swapped Stories website! Visit the live site at [swappedstories.com](https://swappedstories.com)

## Local Build Instructions

1. Clone the repo locally
2. Follow the instructions for [installing Jekyll](https://docs.github.com/en/pages/setting-up-a-github-pages-site-with-jekyll/testing-your-github-pages-site-locally-with-jekyll)
3. Run `bundle exec jekyll serve --baseurl "/swapped-stories" --livereload`
